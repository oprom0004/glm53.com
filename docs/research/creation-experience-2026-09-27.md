# 创作体验完善（2026-09-27）

## 改动

- 选择素材后显示本地图片缩略图或视频播放器、素材名称、文件大小；视频读取元数据后显示时长。首帧、尾帧、Image1、Video1 等标签与提交顺序一致，支持单独移除。移除、替换或离开页面时释放预览 object URL。
- 登录后，根据当前模型、分辨率、时长和输入素材自动获取服务端报价，生成按钮上方显示本次积分及已加载的账户余额。仅修改提示词不会重新报价。
- 参考视频先上传并核验真实时长，再报价；上传及报价不会创建生成任务或扣除生成积分。同一账号下同一 File 的并发报价复用上传，缓存使用 WeakMap，切换账号后重新创建。
- 参数、素材、账号改变时立即隐藏旧报价；报价完成前禁止提交。晚到的旧响应不会覆盖当前报价。报价失败支持重试。
- 点击生成时再次核价；价格变化则停止提交、刷新显示，等待用户再次点击。服务端仍会在扣分前检查 expectedCredits。
- “我的视频”根据已有任务参数区分文生、图生、首尾帧、参考图片、参考视频和混合参考，并显示 Standard / Prime。历史记录没有相应数据时不猜测类型；不会向页面增加源素材 URL 或签名凭据。
