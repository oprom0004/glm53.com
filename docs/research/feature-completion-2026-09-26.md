# 功能完善与验收记录

日期：2026-09-26。项目：`I:/jp/code/wanai30.com`。

## 本轮修复和补充

1. **登录与注册**：弹窗复用完整表单，统一邮箱校验、密码显示、密码确认、错误提示和键盘操作。手机弹窗可滚动。弹窗登录不再触发整页跳转，保留生成器提示词和已选图片；验证邮箱跳转前关闭弹窗。
2. **密码管理**：账户安全页加入真正的修改密码操作，检查当前密码、确认新密码，并撤销其他会话。新增找回密码和重置密码页。仅在邮件服务及发件地址已配置时提供发送能力；无效令牌显示可恢复错误，不显示虚假成功提示。
3. **第三方登录**：Google 作为登录页、注册页及弹窗的首选入口，配置缺失时仍展示入口并明确提示不可用；GitHub 在配置完整后展示。授权弹窗的无效供应商或请求失败会显示错误和返回入口；清理弹窗轮询计时器。Google 返回时校验服务端会话并通知当前页面刷新登录状态，弹窗登录不整页刷新。
4. **生成器**：区分模型读取中、读取失败和未配置，显示实际不可用原因并提供“重新检查”，配置完成后不必刷新整个页面。失败提示不再无条件承诺积分已返还。
5. **后台配置检查**：新增 `/admin/settings/setup`，列出邮箱、Google、R2、AI、各版本模型、Stripe 和邮件服务的配置缺项，显示本环境 Google 回调地址。检查页不会调用收费接口或暴露密钥值。
6. **账户资料**：提交修改时重新读取当前登录用户，不信任浏览器传来的用户身份，也不沿用页面渲染时的旧身份。
7. **验证回调**：邮箱验证页沿用站内回调路径校验。找回密码、密码重置和验证邮箱页面不使用公开页面缓存。
8. **初始化命令**：修复 `rbac:init`、`rbac:assign` 等脚本默认寻找不存在的 `.env.development` 的问题；没有环境专用文件时读取 `.env`，显式指定但不存在的文件会报错。

原安全页的“删除账户”按钮只是跳回自身，未执行任何删除；本轮移除了这个占位入口。账户删除未实现，需要先明确有效订阅、剩余积分及历史账单的处理规则。

9. **测试运行器**：改用 Node 测试 API 的精确文件列表，避免将 Next.js 的 `[参数]` 路径当作通配符而静默遗漏用例；保留 Windows 临时数据库清理所需的 GC 设置。

## 尚未完成的真实服务验收

功能代码、缺项提示及配置入口已补齐。本地环境尚未配置下列服务，因此不宣称已经全功能可用：

| 服务    | 必要配置                                                     | 配置后的验收                         |
| ------- | ------------------------------------------------------------ | ------------------------------------ |
| Google  | 登录开关、OAuth Client ID、Client Secret、正确回调地址       | 实际 Google 账户授权和回站登录       |
| Wan API | API Key、接口地址、实际可用的 Standard/Prime 和各版本模型 ID | 文生、图生、参考生成及异常恢复       |
| R2      | S3 凭据、桶、端点/账户 ID、公开域名                          | 图片上传、生成结果保存、播放和下载   |
| Stripe  | 开关、服务端密钥、Webhook Secret、相应事件与 Portal 配置     | 测试购买、积分到账、续费、取消和退款 |

下一步优先接入 Google：向同事确认是否已有 OAuth Web 客户端，直接通过服务端环境变量配置，不必先用邮箱注册。详细字段和回调地址见 [Google 登录接入](../google-login-setup.md)。需要后台管理时，再将自己的账户绑定管理员角色。不要把密钥发到聊天。完成各项真实服务测试后再部署。
